# 🏢 Agencia B2B Internacional — Sistema Multi-Agente Autónomo

## Arquitectura

```
                    ┌─────────────────────┐
                    │   USUARIO (Cliente)  │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │  SOCIAL MEDIA        │
                    │  STRATEGIST (Lead)   │
                    │  ── Entrevista ──    │
                    └──────────┬──────────┘
                               │ Briefing
                    ┌──────────▼──────────┐
                    │  PROJECT MANAGER     │
                    │  (Orquestador)       │
                    └──────────┬──────────┘
                               │
        ┌──────────┬───────────┼───────────┬──────────┐
        ▼          ▼           ▼           ▼          ▼
   ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐
   │CREATIVO │ │MARKETING│ │VENTAS   │ │TÉCNICO  │ │ANALÍTICO│
```

## Flujos de Trabajo

1. **00-intake.md** — Entrevista inicial (Social Media Strategist → Usuario)
2. **01-strategy.md** — Definición de estrategia
3. **02-content.md** — Producción de contenido
4. **03-performance.md** — Campañas pagadas y performance
5. **04-sales-funnel.md** — Lead generation y funnel
6. **05-analytics.md** — Medición y optimización continua

## Uso

El sistema es autónomo. El usuario solo habla con el Social Media Strategist.
El resto de agentes trabajan en cadena según los flujos definidos.
