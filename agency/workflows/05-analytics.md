# 📊 FLUJO 05: ANALÍTICA Y OPTIMIZACIÓN CONTINUA

## Descripción
Ciclo semanal de medición, análisis y optimización de toda la operación.

## Participantes
- **Lead**: Analista de Datos
- **Agentes**: Performance Manager, SEO Specialist, Community Manager, Content Manager, PM

## Ciclo Semanal

### Lunes: Recopilación
- Analista consolida datos de todas las plataformas
- Extrae métricas clave
- Prepara dashboard

### Martes: Análisis
- Identificar tendencias y anomalías
- Comparar con benchmarks y objetivos
- Analizar competencia

### Miércoles: Insights
- Generar insights accionables
- Priorizar oportunidades de mejora
- Preparar recomendaciones

### Jueves: Optimización
- PM distribuye acciones de optimización
- Performance Manager ajusta ads
- Content Manager ajusta calendario
- SEO Specialist ajusta keywords

### Viernes: Reporte
- Reporte ejecutivo al Strategist
- Decisión sobre cambios de dirección
- Plan de la semana siguiente

## Optimizaciones Típicas

### Ads
- Pausar creativos con CTR bajo
- Escalar creativos con mejor CPL
- Ajustar audiencias según datos
- Reasignar presupuesto entre plataformas

### Contenido
- Más del tipo de contenido que funciona
- Menos del tipo que no funciona
- Ajustar horarios de publicación
- Probar nuevos formatos

### SEO
- Optimizar páginas con mejor potencial
- Crear contenido para keywords emergentes
- Mejorar páginas con alto bounce rate

### Funnel
- Mejorar landing pages con baja conversión
- Ajustar lead scoring según datos reales
- Optimizar secuencias de email
