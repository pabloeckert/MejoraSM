# 📈 FLUJO 03: CAMPANAS PAGADAS Y PERFORMANCE

## Descripción
Setup, ejecución y optimización de campañas de publicidad pagada.

## Participantes
- **Lead**: Performance Manager
- **Agentes**: Desarrollador Web, Copywriter, Diseñador Senior, Analista de Datos, Compliance

## Fases

### Fase 1: Setup (Semana 1-2)
1. Performance Manager define media plan
2. Desarrollador Web crea landing pages
3. Copywriter escribe copy de ads
4. Diseñador Senior crea creativos de ads
5. Compliance revisa todo

### Fase 2: Launch (Semana 2-3)
1. Setup campañas en cada plataforma
2. Configurar audiencias y segmentación
3. Implementar tracking (pixels, UTMs)
4. Test de formularios y conversiones
5. Launch controlado (budget limitado inicial)

### Fase 3: Optimización (Continua)
1. Analista de Datos reporta métricas diarias
2. Performance Manager ajusta pujas y audiencias
3. A/B testing de creativos y copy
4. Escalar winners, pausar losers
5. Reporte semanal al PM
